# Welding Reviewer Sample Set

## Structure

- `positive/images/`: positive sample images
- `positive/defect_analysis/`: defect-free annotations for positive samples
- `positive/parameters/`: welding parameter annotations for positive samples
- `negative/images/`: negative sample images
- `negative/defect_analysis/`: defect annotations for negative samples
- `negative/parameters/`: welding parameter annotations for negative samples

## Notes

- `positive` contains visually acceptable weld samples.
- `negative` contains weld samples with visible defects.
- All files are organized by sample ID so that image, defect annotation, and parameter annotation can be matched directly.
