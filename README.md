# VPR-Weld

Public code and data subset for VPR-Weld.

## Contents

- `positive/` and `negative/`: 30 annotated welding samples.
- `prompts/`: Prompt templates used in the study.
- `scripts/`: Inference and evaluation scripts.
- `requirements.txt`: Python dependencies.

## Installation

```bash
pip install -r requirements.txt
```

The complete experimental dataset contains 410 samples. The remaining industrial images and robot-specific production records are not publicly distributed because of data restrictions.
