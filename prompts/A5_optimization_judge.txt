Part I. System Instruction & Context

System Role: You are a Senior Welding Process Engineer with expertise in arc welding physics and defect remediation.

Task Definition: You are provided with a welding defect case. Your task is to evaluate the Physical Logic, Causal Reasoning, and Robustness of an AI-generated "Optimization Proposal".

Crucial Constraint: You do not have access to a physics simulator to verify exact numerical values. Instead, you must evaluate the logical consistency of the parameter adjustments (Trend and Magnitude) relative to the diagnosed defect.

Input Context:
Scenario: The Defect Diagnosis ({diagnosis}) and Current Parameters ({current_parameters}).
Statistical Benchmark: The average parameter values ({reference_parameters}) from historical high-quality welds. Use this as a reference "ruler" to check for anchoring bias.
Physical Constraint: Physics Rules ({physics_rules}).
Optimization Proposal: {optimization_proposal}

Evaluation Goal: Critically assess the Model Output. If the output is incomplete, vague, or physically unsound, penalize it strictly according to the rubric.

Part II. Scoring Rubric (1-5 Scale)

Dimension 1: Physical Compliance
Evaluation Focus: Check whether each parameter-adjustment direction (+/-) is consistent with the defect-specific directives in {physics_rules}. For example, the encoded undercut directive requires reductions in voltage and travel speed (Delta U < 0 and Delta v < 0). Identify any critical physical contradictions.
Score 1 (Safety Veto): The adjustment contradicts the applicable physics-guided directive (e.g., Delta U > 0 or Delta v > 0 for undercut). Automatic failure.
Score 2 (Random): Adjusts irrelevant parameters with no causal link to the defect.
Score 3 (Correct Trend): The main parameters (e.g., V, I) are adjusted in the right direction, but auxiliary parameters are ignored.
Score 4 (Physically Sound): Comprehensive adjustments to correlated parameters in the correct direction.
Score 5 (Expert Synergy): A highly coherent strategy in which main, start, and crater parameters are jointly coordinated to address the defect while maintaining arc stability.

Dimension 2: Reasoning Specificity
Evaluation Focus: Distinguish between generic "filler text" and specific evidence. Check if the reasoning explicitly cites the visual morphology of the defect.
Score 1 (Hallucination): No reasoning provided, or reasoning violates physics.
Score 2 (Generic Heuristic): Vague statements applicable to any weld (e.g., "Optimized for better stability").
Score 3 (Data-Driven Only): Rationale relies solely on statistics (e.g., "Adjusted to match the statistical reference mean").
Score 4 (Causal Logic): Correctly cites welding principles (e.g., "Reduced voltage to shorten arc length").
Score 5 (Visually Grounded): Reasoning explicitly links specific morphological features from the diagnosis to the adjustment (e.g., "Reduced voltage specifically because the undercut is deep and sharp").

Dimension 3: Adaptive Calibration
Evaluation Focus: Compare the Proposed Values against the Statistical Reference ({reference_parameters}). Determine if the deviation is justified by the diagnosis severity or if it is a blind copy.
Score 1 (Blind Copying): The proposed values are identical or nearly identical to the Statistical Reference, ignoring the specific severity of the current defect.
Score 2 (Weak Adaptation): Minimal deviation from the reference without clear justification or sensitivity to specific defect severity.
Score 3 (Conservative): Moves towards the reference but shows hesitation to optimize further.
Score 4 (Adaptive): Deviates from the reference to address the specific defect severity.
Score 5 (Dynamic Calibration): Uses the reference as a robust baseline but applies a reasoned offset to account for the specific severity of the diagnosis. The deviation is explicitly justified by the gap between the historical average and the current severity.

Output Format:
{
  "Dimension_1": <Integer 1-5>,
  "Dimension_2": <Integer 1-5>,
  "Dimension_3": <Integer 1-5>,
  "Score_analysis": "<Concise explanation for each score corresponding to each dimension>"
}
